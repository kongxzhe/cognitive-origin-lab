# The Four-Stage Cognitive Model

## Overview

The four-stage model describes how a cognitive system processes novel or challenging information. It is a cycle that can be entered at any stage and can repeat indefinitely.

## Detailed Stages

### 1. Unknown (不明)

**Characteristics:**
- The system cannot activate any understanding module above threshold.
- Inputs are either ignored or trigger only low-level perceptual modules.
- The system may wait for more input or engage in random exploration.

**Cognitive State:** Confusion, openness, receptivity.

**Example:** A baby seeing a complex machine for the first time.

### 2. Chaos (混乱)

**Characteristics:**
- Multiple understanding modules are partially activated.
- Conflicting interpretations coexist.
- The system may try multiple actions in sequence or in parallel.

**Cognitive State:** Overwhelm, creativity, exploration.

**Example:** A scientist considering multiple hypotheses for an unexpected result.

### 3. Inverted (颠倒)

**Characteristics:**
- One understanding module becomes dominant.
- The system has a clear interpretation, but it may be wrong.
- Conflicting evidence is ignored or rationalized.

**Cognitive State:** Certainty, confidence, potential delusion.

**Example:** A person believing a conspiracy theory despite evidence to the contrary.

### 4. Unified (合一)

**Characteristics:**
- The dominant understanding module is correct and well-integrated.
- The system can predict accurately and act efficiently.
- New evidence is easily incorporated.

**Cognitive State:** Mastery, fluency, satisfaction.

**Example:** An expert solving a problem in their field with ease.

## Transitions Between Stages

- **Unknown → Chaos:** When the system starts to generate hypotheses.
- **Chaos → Inverted:** When one hypothesis becomes dominant.
- **Inverted → Unified:** When the hypothesis is validated and refined.
- **Unified → Unknown:** When new, uninterpretable information appears.
- **Inverted → Chaos:** When contradictory evidence breaks the dominant hypothesis.

## Mechanisms for Stage Transitions

### Regulator
A meta-cognitive module that monitors the system's state and forces stage transitions when necessary. For example, if the system stays in Inverted too long despite failures, the regulator can force it back to Chaos.

### Beauty and Profundity
- Beauty drives the system from Chaos to Inverted and from Inverted to Unified.
- Profundity drives the system from Unified to Unknown and from Inverted to Chaos.

## Applications

This model can be used to:
- Design cognitive systems that avoid getting stuck.
- Understand human learning and creativity.
- Create AI that can genuinely learn and adapt.
