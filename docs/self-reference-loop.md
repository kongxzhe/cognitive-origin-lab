# The Self-Reference Loop

## Definition

A self-reference loop is a process where a system's output becomes part of its future input, and the system has mechanisms to process that self-generated input.

## Mathematical Representation

Let S be the system state, T be the trace history, and P be the positioning function.

The loop is:
1. S(t) is the current state.
2. P(t) = position(S(t), T(t)) – the system's self-location.
3. New state S(t+1) is generated by applying rules R to (S(t), T(t), P(t)).
4. New trace ΔT is created from the transition.
5. T(t+1) = T(t) ∪ ΔT.

This loop is self-referential because P(t) depends on S(t) and T(t), and S(t+1) depends on P(t).

## Components of the Loop

### 1. State (S)
The current configuration of the system. This includes active modules, activation levels, and short-term memory.

### 2. Traces (T)
The accumulated structural changes from past experiences. Traces are not just data; they are changes to the system's processing capabilities.

### 3. Positioning (P)
The system's understanding of where it is in its own cognitive landscape. Positioning answers questions like:
- What stage am I in?
- What understanding modules are relevant?
- How confident am I?

### 4. Rules (R)
The rules that govern state transitions. These rules can be fixed or adaptive. They take the current state, traces, and position as input and produce a new state and new traces.

## How the Loop Creates Self

Without the loop, the system is a passive transformer of inputs. With the loop, the system's own state becomes an object of processing. Over time, this creates a persistent pattern—a self.
