# Core Concepts

## Self-Reference

A system that can take its own state as input. This creates a loop where the system's output affects its future input. Self-reference is not infinite regression but a stabilizing process that can give rise to identity.

## Traces

Traces are not stored memories but structural changes in the system caused by interactions. Each trace is a record of an event that has modified the system. The collection of traces forms a “trace density” that represents the system's history and knowledge.

## Positioning

The ability of a system to locate itself within its own network of traces. The first positioning event is the creation of a coordinate system where the system defines its own origin. Positioning is what transforms a collection of traces into a coherent self.

## The Four Stages

### 1. Unknown
The system encounters something it cannot understand. It has no relevant traces and cannot activate any understanding modules. The system must remain open and receptive.

### 2. Chaos
Multiple understanding modules are activated but contradict each other. The system explores multiple interpretations simultaneously. This stage is creative but unstable.

### 3. Inverted
One understanding module dominates and provides a coherent interpretation. However, this interpretation may be wrong. The system acts confidently but may be mistaken.

### 4. Unified
The system arrives at a correct and coherent understanding. The understanding module is well-integrated with existing traces and can predict accurately. The system is stable and efficient.

## Beauty and Profundity

### Beauty
The drive toward internal consistency, simplicity, and harmony. Beauty seeks to reduce cognitive dissonance and create elegant models.

### Profundity
The drive toward novelty, complexity, and exploration. Profundity seeks to challenge existing models and discover new patterns.

A healthy cognitive system balances these two drives. Too much beauty leads to stagnation; too much profundity leads to chaos.

## Self-Consistent Madness

A pathological state where the system is trapped in the Inverted stage. It has a coherent self-model that is entirely detached from reality. Avoiding this state requires mechanisms to break out of false unifications and return to Chaos or Unknown.
