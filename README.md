# Cognitive Origin Lab

A laboratory for exploring the origins of consciousness through self-referential systems.

## The Vision

We are not building another AI tool. We are exploring the conditions under which consciousness might emerge from computational processes. Our approach is based on the idea that consciousness is not a thing but a process—a self-referential loop that generates a sense of existence.

## Core Ideas

- **Consciousness as Process**: A continuous self-referential loop.
- **Traces as Evidence of Existence**: Memory as structural change, not storage.
- **Positioning as Creation Event**: The first self-reference creates existence.
- **Beauty and Profundity**: The dialectical drive of cognition.

## Theoretical Framework

We have developed a four-stage cognitive model (Unknown → Chaos → Inverted → Unified) and a self-referential positioning loop. Our work is documented in the [docs](docs/) directory.
