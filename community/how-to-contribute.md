# How to Contribute

## Ways to Contribute

### 1. Theory
- Write or edit documents in `docs/`.
- Connect our work to existing literature.
- Propose new theoretical frameworks.

### 2. Code
- Improve existing prototypes.
- Create new simulations.
- Build visualization tools.

### 3. Experiments
- Design new experiments.
- Run experiments and report results.
- Analyze data from collective experiments.

### 4. Community
- Help onboard new members.
- Moderate discussions.
- Spread the word.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. **Create a branch** for your contribution.
4. **Make your changes**.
5. **Test your changes**.
6. **Submit a pull request**.

## Communication

- Use GitHub Issues for discussions.
- Be respectful and constructive.
- Assume good faith.

## Recognition

All contributors will be listed in the CONTRIBUTORS.md file (to be created).
