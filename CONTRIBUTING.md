# How to Contribute

We welcome contributions from everyone, regardless of background. Here are several ways to contribute:

## 1. Explore the Ideas
- Read the [Core Concepts](docs/core-concepts.md).
- Run the prototypes and experiment with them.
- Share your insights and questions.

## 2. Improve the Theory
- Help us refine the theoretical framework.
- Connect our work to existing research.
- Write new documents or improve existing ones.

## 3. Build and Code
- Improve existing prototypes.
- Create new simulations.
- Develop visualization tools.

## 4. Design Experiments
- Propose and design new experiments.
- Help run collective experiments.
- Analyze and document results.

## 5. Spread the Word
- Share our work with others who might be interested.
- Write about our exploration in your own words.
- Help us build a diverse and inclusive community.

## Getting Started with Code

1. Fork the repository.
2. Create a branch for your contribution.
3. Make your changes.
4. Test your changes.
5. Submit a pull request.

## Communication

- We use GitHub Issues for discussions and project management.
- Be respectful and open-minded.
- We are all here to learn and explore together.

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
